# Triage labels

| Role | Label | Meaning |
|---|---|---|
| Untriaged | `needs-triage` | An incoming request has not been classified. |
| Needs information | `needs-info` | Essential information is missing; state what is needed and from whom. |
| Ready for an agent | `ready-for-agent` | Scope, acceptance criteria, and dependencies are sufficiently explicit for agent implementation. |
| Ready for a human | `ready-for-human` | The request is understood but needs human implementation or action. |
| Will not implement | `wontfix` | A deliberate decision not to implement; record the reason. |

Use these labels as readiness roles rather than cumulative progress markers.
Generated specifications and implementation tickets do not need another triage
pass. Blocking relationships are separate from readiness labels.
