# Agent instructions

## Agent skills

### Issue tracker

Before creating, updating, or implementing a specification or ticket, read
[docs/agents/issue-tracker.md](docs/agents/issue-tracker.md). Use GitHub Issues and
`gh` for this repository's planning workflow.

### Triage labels

Before classifying an incoming request or changing an issue's readiness, read
[docs/agents/triage-labels.md](docs/agents/triage-labels.md).

### Domain docs

Before designing, implementing, or reviewing behavior, read [CONTEXT.md](CONTEXT.md)
and the relevant decisions in [docs/adr/](docs/adr/). The reading and maintenance
contract is in [docs/agents/domain.md](docs/agents/domain.md).
